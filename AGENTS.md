# Project rules

- Keep case-study narratives and section definitions in the project data layer, and render them through the shared editorial section component and `cs-*` template styles (fixed section order, group labels, reusable feature/split/two/three layouts) so every case study stays consistent.
- Keep existing project slugs stable when updating names or content so previously shared links continue to work.
- Scope Work index presentation tokens to its page wrapper and use the shared ProjectCard for aligned image/caption tracks so refinements do not restyle unrelated pages.
