# Project memory

## Product intent & audience

- User maintains an existing personal portfolio site for a senior brand designer.
- Audience: potential clients/collaborators; currently positioned as "senior brand designer professional" in English.
- User admires the luudsgn (Lucía Antúnez) portfolio and is considering moving toward a warmer, more authorial, narrative style.

## Brand personality & voice

- Current voice: professional, English, editorial.
- Aspirational reference (luudsgn): personal, warm, Spanish, narrative copy ("De una idea desordenada a algo clara…").
- Open decision: full language/tone shift to Spanish + authorial, or keep English and adopt only select visual elements.

## Visual design & UX direction

- Existing portfolio already shares editorial aesthetic: serif typography, cream background, scroll reveals.
- Reference style highlights to potentially adopt:
  - Large italic serif typography as protagonist.
  - Narrative single-page home structure: hero → projects → collaborations/services → about → contact.
  - "Colaboraciones" and "Herramientas" sections showing process.
  - Image gallery with captions ("1 imagen dice más que 1000 palabras").
  - Highly editorial project detail pages with images and per-section explanatory text.
- Project detail pages likely already exist; home is candidate for restructuring.

## Decisions, constraints & rationale

- Tradeoff identified: switching English→Spanish and professional→personal tone repositions portfolio from "senior professional" to "warm/authorial."
- No decision yet on scope of transformation; awaiting user confirmation.

## Open questions & assumptions

- Language: adopt Spanish fully or keep English?
- Scope: full restyle to luudsgn narrative structure, or incremental visual borrowings (italic serif, collaborations/tools sections)?
- Assumption: user is open to restructuring the home into a single-page narrative flow.
